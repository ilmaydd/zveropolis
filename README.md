# Зверополис · Түнгі эфир

QAIRU AI Fundamentals финалына арналған қазақша браузер ойыны. Фестивальдегі жалған хабардан кейін Джуди мен Ник үш ауданда тергеу жүргізеді. Саванна орталығында фургонның жолын кеседі, Тропик ауданында релеге ток береді, ал Тундратаунда шын жазбаны эфирге қосады.

## Іске қосу

Архивті ашып, `dist/index.html` файлын браузерде ашыңыз. Ойынға сервер, сыртқы кітапхана немесе API кілті қажет емес. Қууда WASD, бағыт пернелері, экрандағы батырмалар немесе көрші ұяшықтар қолданылады. Қалған екі бөлімде пульт пен дәліз батырмаларын басыңыз. Аяқталған кезеңдер жергілікті жадта сақталады.

## Техникалық сипаттама

| Апта және әдіс | Кіріс пен мақсат | Қадамдар және нәтиже | Шектеулер |
| --- | --- | --- | --- |
| 2 · A* іздеуі | Джуди мен фургонның орны, көше тосқауылдары, әр нүктеде қалған жүріс саны | Фургонның келесі нүктелерін ретімен тексереді. A* әр нүктеге дейін жүрілген және болжамды қашықтықты есептейді. Уақытында жетуге болатын жол картада көрсетіледі | Төрт бағыт, қадам құны бірдей. Фургонның бағыты мен қозғалу жиілігі алдын ала белгілі |
| 3 · CSP | Пайдаланушы таңдаған сымдар және әр ұяға рұқсат етілген түстер | Әр бос ұяға рұқсат етілген түсті байқайды. Бір түс қайталанса, тармақты алып тастайды. Пульт жарамдылықты және кеңес батырмасы келесі таңдауды көрсетеді | Төрт ұя және алдын ала берілген ережелер. Бірнеше дұрыс шешім болуы мүмкін |
| 4 · Минимакс | Джудидің орны, Беллуэзердің тосқауылы және дәліздегі қабырғалар | Джуди үшін нәтижені жақсартатын, ал Беллуэзер үшін нашарлататын жүрістерді кезекпен тексереді. Компьютер тосқауылды және кеңес тиімді жүрісті таңдайды | Алты баған, төрт жолақ және толық көрінетін күй. Тереңдігі дәліз ұзындығымен шектелген |

`dist/ai.js` есептеуді орындайды. `dist/game.js` кезең күйін, енгізуді, интерфейсті және сақтауды басқарады. Карта, пульт және дәліз браузерде көрсетіледі.

## Тесттер

```sh
node --test tests/*.test.cjs
```

Node.js 18+ қажет. Төрт автоматты тест жабық жолдағы A*, реленің жарамды және қайшы күйлері, Минимакстың ұтысты және ұтылатын жүрістері, сондай-ақ үш кезеңнің соңына дейін өтуін тексереді.

## GitHub Pages

Архивті ашып, файлдарды GitHub репозиторийіне, оның ішінде `.github` бумасын жүктеңіз. **Settings → Pages → Source → GitHub Actions** таңдаңыз. **Actions → Publish game to GitHub Pages → Run workflow** арқылы жариялаңыз.

Кейіпкерлер Disney-дің «Зверополис» фильмінен. Фестиваль оқиғасы мен ойын ережелері осы жоба үшін жазылған. Дереккөз — QAIRU AI Application Development Challenge 2026 тапсырмасы. Сценарий, интерфейс, код пен иллюстрация генеративті ЖИ көмегімен әзірленді.
